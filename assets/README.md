# Assets Directory

This directory contains app assets like icons, splash screens, and images.

## Required Assets for EZ Clear

### App Icons
- `icon.png` - 1024x1024 app icon
- `adaptive-icon.png` - 1024x1024 adaptive icon for Android
- `favicon.png` - 32x32 favicon for web

### Splash Screen
- `splash.png` - 1284x2778 splash screen image

### Placeholder Assets
For development, you can use simple colored rectangles or the Expo default assets until you have the final designs.

## Asset Guidelines

- **App Icon**: Should feature the EZ Clear logo with the teal (#00E6CF) brand color
- **Splash Screen**: Dark background (#0B0F1A) with centered logo
- **Format**: PNG with transparency support
- **Optimization**: Use tools like ImageOptim or TinyPNG to reduce file sizes
